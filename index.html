Why Reduce Polygons in SketchUp?

Every face (polygon) in a SketchUp model adds to file size, slows down the viewport, and increases rendering times. Understanding where polygons come from helps you target the right areas.

The most common sources of polygon bloat

Circles and arcs are the #1 culprit — SketchUp represents them as flat-sided polygons. A default circle has 24 segments, meaning a simple cylinder has 48 faces just for the barrel. Import from 3D Warehouse is the #2 cause — models downloaded from the warehouse are often designed for rendering, not performance, and can have millions of unnecessary faces.

  • Circles/arcs: Default 24 segments × every cylinder/dome in model
  • 3D Warehouse imports: Often 10-50× more faces than needed for your purpose
  • CAD imports (.dwg, .dxf): Precise engineering geometry, extremely high polygon count
  • Hidden internal geometry: Boolean operations leave interior faces invisible but still counted
  • Entourage models: People, trees, cars from the warehouse are notoriously heavy

Performance impact by use case

The acceptable polygon count varies dramatically based on what you're doing with the model. A model optimized for SketchUp rendering (Enscape, V-Ray) can have far more polygons than one destined for a game engine or real-time web viewer.

  • SketchUp viewport: Over 500,000 faces → slow orbit and pan
  • Enscape / V-Ray rendering: Over 5 million faces → long render times
  • Unity / Unreal Engine: Hero object should be under 10,000 faces
  • Web AR (three.js, Babylon.js): Under 50,000 faces total per scene
  • VR (Meta Quest, PCVR): Under 100,000 faces for 90fps on Quest

How to Check Your Polygon Count in SketchUp

Before optimizing, measure. SketchUp calls polygons "faces" in its statistics panel.

Using Model Info Statistics

Go to Window → Model Info → Statistics. Click "Show nested components" to see the total face count across all groups and components, not just the top-level geometry. The key number is Faces — this is your polygon count. Edges will always be roughly 3× the face count for triangulated geometry.

Using the Entity Info Panel

Select a specific component or group, then open Window → Entity Info. This shows the face and edge count for just that selection. Use this to identify which specific component is the heaviest. Sort by selecting different parts of the model — the heavy ones are usually immediately obvious in the Entity Info count.

Methods to Reduce Polygons in SketchUp

From quickest (no plugins needed) to most powerful (external tools). Apply in this order — the native methods often solve 80% of the problem.

Native SketchUp Methods (No Plugins)

1. Reduce Circle and Arc Segments Free · Built-in
The single biggest win for most SketchUp models. Every circle is a polygon — fewer sides means fewer faces.
  1. Select a circle or arc in your model
  2. Open Window → Entity Info
  3. Change the Segments field — from 24 to 8 or 12
  4. SketchUp rebuilds the arc/circle with fewer sides
  5. Repeat for all circles throughout the model
Changing from 24 to 8 segments reduces a circle's edge count by 67%. A model with 100 cylinders (pipes, columns, furniture legs) can lose hundreds of thousands of faces this way.
2. Delete Hidden Geometry Free · Built-in
Boolean operations and CAD imports leave interior faces that are invisible but still counted.
  1. Enable View → Hidden Geometry (dotted lines appear)
  2. Select the model or component
  3. Use Edit → Select All then manually deselect visible geometry
  4. Or use Edit → Intersect Faces → With Model to expose and then delete internal faces
  5. Disable View Hidden Geometry when done
3. Use Soften/Smooth Edges to Merge Coplanar Faces Free · Built-in
SketchUp sometimes creates multiple coplanar triangles where a single face should exist. Softening edges merges them visually.
  1. Select the geometry you want to simplify
  2. Open Window → Soften Edges
  3. Drag the Angle slider right — higher angle merges more edges
  4. Check "Smooth normals" to reduce jagged shading artifacts
Note: this doesn't actually delete geometry — it just hides edges. Use with caution since it affects how the model renders in some exporters.
4. Replace Heavy Components with Low-Poly Alternatives Free
The most effective strategy for entourage (people, trees, cars): replace the entire heavy component with a purpose-built low-poly version.
  1. Identify the heaviest components via Entity Info
  2. Search 3D Warehouse specifically for "low poly" versions (e.g. "low poly tree", "low poly person")
  3. Use SketchUp's native 2D people (face-me components) for background figures — near-zero polygon cost
  4. For vegetation: use Skatter plugin's billboard faces instead of 3D tree models

Plugin-Based Reduction (For Imported Complex Models)

Skimp — Polygon Reduction Inside SketchUp $79 one-time
The most popular dedicated polygon reducer for SketchUp. Works directly inside SketchUp without leaving the application. Simplifies meshes using quadric error metrics — preserves shape while reducing face count.
  1. Install Skimp from skimp4sketchup.com ($79, one-time license)
  2. Select the component or group to reduce
  3. Open Skimp from Extensions menu
  4. Drag the reduction slider — preview updates in real time
  5. Apply when happy with the result
Best for: imported OBJ, FBX, DAE models with 100,000+ faces that need to stay in SketchUp format. Preserves UV maps and texture coordinates.
Artisan — Organic Sculpting + Subdivision ~$39
Primarily a sculpting tool, but Artisan's "Simplify" tool reduces polygon count on organic shapes (terrain, curved surfaces). Better than Skimp for terrain models.
  1. Install Artisan from Extensions Warehouse (~$39)
  2. Select terrain or organic mesh
  3. Extensions → Artisan → Simplify
  4. Set target face count or reduction percentage
Best for: terrain, landscape, and organic curved surface reduction. Not ideal for hard-surface architectural models.

Export Workflow — Free Reduction via Blender

Export to Blender → Decimate → Reimport Free
Blender's Decimate modifier is a professional-grade polygon reducer — free, powerful, and available to everyone. The tradeoff is it requires leaving SketchUp.
  1. In SketchUp: File → Export → 3D Model → OBJ
  2. Open Blender (free at blender.org) → Import OBJ
  3. Select the imported object → Properties panel → Add Modifier → Decimate
  4. Set Ratio (0.5 = 50% reduction, 0.1 = 90% reduction) and Apply
  5. Export from Blender as OBJ or DAE
  6. Reimport to SketchUp: File → Import
Best for: dramatic reductions (10-90%) where you don't need to preserve SketchUp groups/layers. Free but requires the export-edit-import round trip. UV maps may need manual correction after decimation.

Reduce Polygons in SketchUp – FAQ

How do I reduce polygon count in SketchUp without plugins?+
Three native methods: (1) Reduce circle and arc segments — select any circle, open Entity Info (Window → Entity Info), change the Segments value from 24 to 8 or 12. (2) Delete hidden geometry — enable View → Hidden Geometry to reveal interior faces left by boolean operations, then delete them. (3) Use Soften/Smooth Edges (Window → Soften Edges) to merge coplanar triangles. For heavily imported models (CAD files, 3D Warehouse), these native methods may not be sufficient and you'll need Skimp or the Blender Decimate workflow.
What is the best free way to reduce polygons in SketchUp?+
The best free method is the Blender Decimate workflow: (1) Export from SketchUp as OBJ (File → Export → 3D Model → .obj). (2) Import into Blender (free at blender.org). (3) Select the object, go to the Properties panel → wrench icon → Add Modifier → Decimate. (4) Set Ratio (0.25 = 75% reduction) and Apply. (5) Export as OBJ from Blender and reimport to SketchUp. This is free and gives professional-quality results, but requires the round-trip and may not preserve SketchUp layers/groups.
How many polygons is too many in SketchUp?+
There's no universal limit — it depends on your hardware and use case. As general guidelines: under 200,000 faces = smooth navigation on most computers. 200,000–1,000,000 = may get sluggish, especially with textures. Over 1,000,000 faces = expect lag on most machines. The SketchUp official recommendation is to keep models as lean as possible. Check Window → Model Info → Statistics to see your current count. The Poly Budget Calculator on this page gives specific targets based on your end use (game engine, rendering, VR, web).
Does Skimp work with SketchUp Free (web version)?+
No. Skimp (and most SketchUp plugins) require SketchUp Pro or SketchUp Go (subscription). The web-based SketchUp Free does not support extensions. If you're on SketchUp Free and need polygon reduction, the Blender export workflow is your best free option — it works regardless of which SketchUp version you have, since it operates on the exported OBJ file rather than inside SketchUp.
How do I reduce polygons in a 3D Warehouse model I downloaded?+
3D Warehouse models often have extremely high polygon counts because they're designed for visual fidelity, not performance. Steps: (1) After importing, check the face count in Entity Info by selecting the component. (2) For models under 50,000 faces, try reducing circle segments and hidden geometry deletion. (3) For models over 50,000 faces, use Skimp ($79) to reduce them directly in SketchUp. (4) For free reduction, export as OBJ and use Blender's Decimate modifier. (5) As a workaround, search 3D Warehouse for "low poly" versions of the same object — many popular items have community-made low-poly alternatives.
